## Principles behind the artifacts

- **We don't build an architecture for tech. We build a business.**
- North Star high-level by design (80/20); the next release with full clarity, agreed top to bottom.
- Team setup follows architecture, not the other way around.
- Nothing new by design — assembled from proven practices (Pichler, impact mapping, story mapping, C4, evolutionary architecture) into something a division can actually run.
